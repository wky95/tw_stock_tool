API VERSION 1

串接文件

本機 JSON API。成功回應格式為 {"ok":true,"result":...}，失敗則包含穩定的 error.code 與可讀的 error.message。

GET/api/v1/capabilities

列出目前啟用的歷史與盤中資料 provider、券商狀態及策略。

POST/api/v1/backtests

{
  "source": "api",
  "market": "tse",
  "symbol": "2330",
  "start": "2023-01-01",
  "end": "2025-12-31",
  "strategy": "sma_cross",
  "params": {"fast": 20, "slow": 60},
  "config": {"initial_cash": 3000000}
}

market 可為上市 tse 或上櫃 otc。CSV 模式傳入 source: "csv" 與 csv_text。

POST/api/v1/monitor/snapshot

{
  "instruments": ["2330:tse", "6488:otc"],
  "alerts": [{
    "id": "my-rule",
    "instrument": "2330:tse",
    "condition": "above",
    "threshold": 2000,
    "enabled": true
  }]
}

條件支援 above、below、change_pct_above、change_pct_below。單次最多 50 檔。

POST/api/v1/factors/discover

{
  "instruments": ["2330:tse", "2317:tse", "6488:otc"],
  "start": "2024-01-01", "end": "2025-12-31",
  "horizon": 5, "train_ratio": 0.7, "top_k": 6
}

計算所有已註冊因子的訓練與樣本外 Rank IC，並排除高度相關因子。

POST/api/v1/factors/synthesize

{
  "instruments": ["2330:tse", "2317:tse", "6488:otc"],
  "start": "2024-01-01", "end": "2025-12-31",
  "horizon": 5, "train_ratio": 0.7,
  "factor_keys": ["momentum_20", "volume_ratio_5"],
  "method": "ic_weighted"
}

方法可為 equal、ic_weighted 或 icir_weighted。

GET/api/v1/openapi.json

機器可讀的 OpenAPI 入口。完整 adapter 擴充說明位於 repository 的 docs/ARCHITECTURE.md。
